Format : [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/) ; versions : [SemVer](https://semver.org/lang/fr/). Les entrées suivantes sont générées par Changesets.

## 1.0.0 — 2026-10-23

Première version publique.

### Ajouté

- Saisie rapide avec calcul dans le montant, suggestions, brouillon, virements, remboursements, charges sans date.
- Liste des opérations : recherche, filtres dans l’URL, sélection multiple, corbeille, annulation.
- Budgets par catégorie et global avec report, reconduction et alertes.
- Tableau de bord et analyses avec tables de données et exports PNG / CSV.
- Récurrences, règles de catégorisation, tags, objectifs d’épargne, comptes multiples.
- Import du classeur Finances `.xlsm` avec contrôle des soldes F2, relevés CSV / OFX / QIF, sauvegarde JSON de référence et chiffrée, exports CSV / XLSX, annulation d’import.
- Sauvegardes automatiques locales, migrations de schéma, journal d’erreurs local.
- PWA hors ligne, CSP stricte et Trusted Types, français et anglais, thème clair / sombre, accessibilité RGAA / WCAG 2.2 AA.
