# 0002 — Choix de la pile technique

- Statut : accepté
- Date : 2026-10-23

Dernières versions stables au démarrage, figées par `pnpm-lock.yaml`.

| Couche                  | Choix                                                                            | Écart au cahier des charges et justification                                                                                                                                                                                                         |
| ----------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Langage                 | TypeScript 6.0 strict (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`) | TypeScript 7 (réécriture native) n’est pas encore supporté par typescript-eslint.                                                                                                                                                                    |
| Build                   | Vite 8 (Rolldown)                                                                | —                                                                                                                                                                                                                                                    |
| UI                      | React 19                                                                         | —                                                                                                                                                                                                                                                    |
| Routage                 | TanStack Router, historique _hash_                                               | Le _hash_ évite toute règle de réécriture serveur : l’archive .zip fonctionne sur n’importe quel hébergement statique, y compris dans un sous-dossier. Filtres dans l’URL, typés par Zod.                                                            |
| Stockage                | IndexedDB via Dexie 4, `liveQuery`                                               | —                                                                                                                                                                                                                                                    |
| État d’interface        | Zustand (toasts, panneau de saisie)                                              | —                                                                                                                                                                                                                                                    |
| Validation              | Zod 4 en mode `jitless`                                                          | `jitless` : Zod n’essaie jamais `new Function` (CSP sans `unsafe-eval`).                                                                                                                                                                             |
| Montants                | Objet valeur maison en centimes, rationnels BigInt dans l’analyseur              | —                                                                                                                                                                                                                                                    |
| Expression de montant   | Shunting-yard maison, arithmétique exacte                                        | —                                                                                                                                                                                                                                                    |
| Dates                   | Module maison de dates civiles (algorithmes de Howard Hinnant)                   | date-fns raisonne en heure locale ; des dates civiles sans fuseau n’en ont pas besoin. 120 lignes testées par propriétés.                                                                                                                            |
| Graphiques              | Apache ECharts 6 (import à la demande, rendu canvas, info-bulles `richText`)     | `richText` évite toute injection HTML (Trusted Types).                                                                                                                                                                                               |
| XLSX / XLSM             | Lecteur et écrivain maison (fflate + fast-xml-parser)                            | ExcelJS embarque des polyfills incompatibles avec une CSP stricte et pèse ~900 Ko ; SheetJS CE n’est plus publié sur npm. Le lecteur ne lit que les valeurs, refuse les DTD, borne la décompression (zip bomb) et n’extrait jamais `vbaProject.bin`. |
| CSV                     | Papa Parse                                                                       | —                                                                                                                                                                                                                                                    |
| Composants              | Éléments HTML natifs (`<dialog>`, radios, `<select>`) + CSS Modules et tokens    | Radix UI injecte des balises `<style>` (react-remove-scroll, Select) bloquées par `style-src 'self'`. Le `<dialog>` natif fournit le piège de focus, l’arrière-plan inerte et Échap.                                                                 |
| PWA                     | vite-plugin-pwa (Workbox), stratégie _prompt_                                    | —                                                                                                                                                                                                                                                    |
| i18n                    | FormatJS (react-intl), ICU                                                       | —                                                                                                                                                                                                                                                    |
| Chiffrement             | Web Crypto (AES-GCM 256, PBKDF2-SHA-256 600 000 itérations)                      | —                                                                                                                                                                                                                                                    |
| Icônes                  | lucide-react (ISC)                                                               | —                                                                                                                                                                                                                                                    |
| Polices                 | Polices système                                                                  | Aucune police à héberger ni à licencier ; rendu natif sur iOS et Android.                                                                                                                                                                            |
| Tests                   | Vitest 5 + fast-check, Testing Library, Playwright, axe-core                     | —                                                                                                                                                                                                                                                    |
| Catalogue de composants | Storybook 10 (react-vite, addon a11y)                                            | Stories des composants génériques de `src/ui`.                                                                                                                                                                                                       |
| Budget de taille        | Script `scripts/check-bundle-size.mjs`                                           | size-limit additionne des fichiers par motif ; avec un découpage automatique en chunks, seul le parcours du graphe d’imports depuis `index.html` mesure ce que le navigateur télécharge avant le premier écran.                                      |
